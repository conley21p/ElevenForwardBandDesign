## Research links

- [AE: American & Efird - Sewing Stretch Knit Fabrics](https://www.amefird.com/wp-content/uploads/2010/01/Sewing-Stretch-Kni-tFabrics-2-6-10.pdf) - Operator feeding, stretch seams and sample troubleshooting. Accessed 2026-10-14.
- [COATS: Coats - Soft and Secure Seams](https://www.coats.com/pl/info-hub/about-soft-and-secure-seams-for-activewear-and-intimates/) - Needle / looper thread roles, skin-side softness and extension. Accessed 2026-10-14.
- [SCHMETZ: SCHMETZ - Stretch Needles](https://www.schmetzneedles.com/products/stretch-sewing-machine-needles) - Domestic stretch needle characteristics; use the actual machine needle system. Accessed 2026-10-14.
- [PEGASUS: Pegasus - Stitch Library](https://www.pegasus.co.jp/stitch/index.php?lang=en) - Stitch formation examples; confirm actual machine formation before assigning codes. Accessed 2026-10-14.
- [ISO4915: ISO 4915:1991 - Stitch classification](https://www.iso.org/standard/10932.html) - Terminology reference, not a garment performance certification. Accessed 2026-10-14.
- [ISO4916: ISO 4916:1991 - Seam classification](https://www.iso.org/standard/10934.html) - Seam terminology reference, not a compliance claim. Accessed 2026-10-14.
- [ISO20932: ISO 20932-1:2018 - Fabric elasticity](https://www.iso.org/standard/69489.html) - Laboratory method reference; informal coupon checks here are not ISO tests. Accessed 2026-10-14.
- [ISO6330: ISO 6330:2021 - Washing and drying](https://www.iso.org/standard/75934.html) - Controlled laundering reference; record the actual prototype care process. Accessed 2026-10-14.
