The SVG is a proportional concept drawing, not a production cutting pattern. All material outlines use **30 SVG units per inch**. Browser display and normal printing do not produce a physical 1:1 pattern. Seam allowances and stretch adjustments are not included as established cutting allowances.

Open the SVG in a browser or vector editor. Preserve the common scale when editing; update this documentation with changes. Part #3 is shown once with quantity two. Part #5 was intentionally removed; numbering is retained for discussion continuity.

The ostomy bag is an illustrative sizing reference, not a supplied product component. No material supplier, fabric composition ratio, or branded moisture-wicking technology has been verified. No license is granted by this repository; a license has not yet been selected.
